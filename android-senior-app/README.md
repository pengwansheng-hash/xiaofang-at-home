# 小芳在家 Android 老人端

当前为 Kotlin + Jetpack Compose 原生工程。

已完成：
- Compose 工程骨架
- 底部导航与页面路由
- 首页、提醒页、提醒确认页、语音陪伴页、联系人页
- 新增提醒页
- 提醒详情页按 reminderId 路由
- 提醒编辑、删除、完成、稍后提醒
- 昵称与提醒列表的本地持久化
- AlarmManager + BroadcastReceiver 本地通知调度
- 通知点击回流到指定提醒详情
- 系统 TextToSpeech 播报接入
- 麦克风权限申请、MediaRecorder 录音与本地 m4a 文件保存
- 陪伴页“最近录音”状态回写
- 最近一次录音回放与停止回放
- SpeechRecognizer 语音转写与提醒草稿二次确认保存
- 精确提醒调度、重启后提醒恢复与单次提醒不过期重排
- 本地提醒、本地存储、音频能力的接口分层

当前产物：
- Debug APK：`app/build/outputs/apk/debug/app-debug.apk`

本地构建：
```powershell
.\gradlew.bat assembleDebug --no-daemon --console=plain
```

- DataStore / Room 的正式替换或升级

- 联系人能力的更多边界处理

- 新增首次引导页：首启时优先采集称呼、沟通风格、常聊话题、首位联系人和首个提醒，完成后再进入首页；这批数据仍先落本地缓存，后续再映射到服务端主存储。

## 服务端 AI
- 老人端陪伴回复默认优先请求 care-service 的 POST /api/ai/companion-reply。
- 默认服务地址为 http://10.0.2.2:3301，默认老人 ID 为 senior-zhang。
- 服务不可用时会自动回退本地记忆回复，避免对话中断。

## 服务连接配置
- 绑定页可以修改 care-service 地址和老人 ID。
- 默认地址是 http://10.0.2.2:3301，默认老人 ID 是 senior-zhang。
- 保存后会写入本地偏好，陪伴页会直接读取这份配置。
- 保存服务连接时会自动测试 `/api/ai/runtime`，结果会显示在绑定页的连接状态卡片里。
- 真机测试时请把绑定页里的服务地址改成电脑的局域网 IP（例如 `http://192.168.x.x:3301`），默认 `10.0.2.2` 仅适合模拟器。
- `3201` 是子女端网页前端端口，不是老人端 `care-service` 服务端口。
- 真机连接局域网服务端时如果是 `http://192.168.x.x:3301` 这类明文地址，当前版本已允许 HTTP；如果仍失败，请先确认手机和电脑在同一 Wi-Fi 下。
- 语音陪伴页现在改为单击切换开始/结束，不再强依赖按住说话手势；如果点击后状态没有变化，先看页内“语音状态”卡片。
- 发送文字后会先立即回显到聊天列表，再等待小芳回复。
